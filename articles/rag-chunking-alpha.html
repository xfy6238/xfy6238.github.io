RAG 切片 500/100 与混合检索 α=0.6 是怎么测出来的

阅读约 8 分钟 · 20 条黄金集 · 8 指标 · 4 档切片网格
结论先行

按句聚合 500字 / 重叠100 为当前最优：Hit@3 0.917、Citation 0.75；混合检索 final = 0.6·向量 + 0.4·BM25。评测固定 20 条黄金集，任一指标跌超 0.05 即告警。

背景：这个结论从哪来

这是一次求职匹配 Agent 调优的实测记录：用户输入一句话画像（比如“3 年 Python 后端 + RAG 问答项目”），系统从 JD 库里检出最匹配的 3 个岗位，并给出缺口分析。

其中“检出”一步用的是 RAG——先把 JD 正文切成片段存进向量库，查询时按语义相似度召回，再重排取 Top3。 一句话：切得好不好，直接决定检不检得到、引用回跳对不对。

切片有两个旋钮：每片多大（size）、片之间重叠多少（overlap）。 太大，模型爱从同一片里“脑补”；太碎，一段话被劈成几片，查全率掉。 下面就是用固定评测集把四个尺寸跑一遍，拿数字说话的过程。

1为什么要定量：感觉会骗人

切片调优最常见的坑，是拿两三个例子说“800 字不断句读着更顺”就定稿。顺≠检得准≠引得对。我的做法是先冻结三样东西，再跑网格：

  • 黄金集：20 条——12 条画像→岗位（端到端 Top3 对不对），8 条问题→片段（RAG 切片本身准不准）。
  • 8 个指标：检索看 Hit@3 / Recall@10 / MRR / NDCG@10；切片看 Citation Precision / Faithfulness；成本看向量数 / p50 / Leak 率。
  • 判定口径前置：引用缺失直接 0 分；NDCG 按 expected 3-2-1 加权；Leak（串库/隐私片段混入）单独成项。

2四档网格：300 / 500 / 800 / 1200

四档都用同一套按句聚合（中文句末 + 换行 + 分号切句、保留分隔符，拼到 size 就在句界截断，单句超长才硬切，重叠起点回退到最近句首）。只变 size，overlap 固定 100。

SIZE 向量数 Hit@3 Recall@10 MRR NDCG Citation Faith Leak p50
300 710 0.833 0.695 0.812 0.670 0.75 0.50 0.136 169ms
500 ★ 491 0.917 0.75 0.861 0.727 0.75 0.50 0.189 184ms
800 407 0.917 0.75 0.861 0.722 0.625 0.25 0.189 175ms
1200 368 0.917 0.75 — — 0.625 — — —

注：1200 档召回与 800 持平、引用同样掉到 0.625，未继续细测排序项；★ 为当前最优。

读表三句话：800 和 500 召回一样，但 800 的引用从 0.75 跌到 0.625、保真从 0.5 跌到 0.25——片越大，模型越爱从同一片里“脑补”；300 引用虽保住 0.75，却把一段切成两片，要拼多片才够判，Hit@3 跌到 0.833；500 的 NDCG 0.727 还是四档最高，排序也最优。

3切片算法：按句聚合是关键

固定字符数硬切会在句中腰斩，引用回跳时半句话对不上。实现只有三步，落在 ingest.py chunk_text： 

按 [。！？\n；;] 切句（保留分隔符）
逐句拼装 → 长度将超 size 时在句界截断成片
重叠 overlap 个字符，但起点回退到最近的句首/空格之后

元数据每片都带 url / company / title / salary，引用字符串必须原文命中才算分——这是 Citation 指标能真实反映“可回跳”的原因。

4混合检索：向量 + 自研 BM25

纯向量检索对短词、型号、精确术语不敏感（比如“α”“MJ00xx”这类 token），所以加了一路经典 BM25（k1=1.5、b=0.75，中文按字/词混合分词），加权融合： 

final = α · vec_norm + (1 − α) · bm25_norm    # Top20 取并后重排
α = 0.6（默认，HYBRID_ALPHA 环境变量可调，设 1.0 即退化纯向量）

α 的取值同样是网格定的：0.6 附近检索最稳；往 1.0 走精确词召回掉，往 0.3 走语义排序散。开关用 HYBRID_ENABLED 控制，异常自动回退纯向量，保证演示不断。

5复现清单

  • 代码与评测脚本已开源：jobmatch-agent 仓库（backend/ingest.py、hybrid.py、eval.py）。
  • 切片参数开箱即用：CHUNK_SIZE=500 CHUNK_OVERLAP=100（环境变量可覆盖）。
  • 换成你自己的 JD 后，先 frozen 自己的 20 条黄金集，再跑网格——数字会变，流程不变。
